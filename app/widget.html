Crunch widget

Time left today and your running task, counting down on your home screen and lock screen.

  1. Install Scriptable from the App Store (free).
  2. Tap Copy the widget script above.
  3. Open Scriptable, tap +, paste, then tap the title at the top and name it Crunch. Tap Done.
  4. Home screen: hold an empty spot, tap Edit then Add Widget, pick Scriptable, choose the small size, add it. Tap the widget, set Script to Crunch.
  5. Lock screen: hold the lock screen, tap Customize, then Lock Screen, tap the widget row, add Scriptable (the wide one). Tap it and set Script to Crunch.

iPhone decides when widgets reload (about every 5 to 15 minutes), so a task you start shows up after a short while. The countdowns themselves tick every second.
